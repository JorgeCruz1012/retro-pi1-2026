Evaluación par a par del 1 al 10. Si hay diferencia mayor a 3 puntos entre dos equipos — hay tensión que hablar.

✅ Compromisos para el PI 2

Solo se registra si tiene dueño voluntario y métrica. Máximo 8 compromisos. Sin dueño = no existe.

⏱️ Tiempo sugerido: 60:00
🎙️ Instrucción Por cada prioridad votada (top 5 de la etapa 3): pregunta secuencialmente: "¿Qué acción concreta hacemos?" → "¿Quién se compromete?" → "¿Para cuándo?" → "¿Cómo sabremos que se cumplió?"
Si nadie se ofrece como dueño, el compromiso no se registra. Eso también es información valiosa.

🚀 Plan de abordaje — Retos PI 2

Mapeo de capacidades requeridas vs estado actual. Donde hay brecha alta, hay riesgo para el PI.

⏱️ Tiempo sugerido: 45:00
🎙️ Instrucción Revisa cada capacidad. El equipo asigna un estado actual (1-5). La brecha (5 - estado actual) se calcula sola. Al final identifica las capacidades con brecha ≥ 3 — esas son las más críticas para el PI. Pregunta de cierre: "¿Qué tendríamos que ver al final del PI 2 para saber que vamos bien en este reto?"
